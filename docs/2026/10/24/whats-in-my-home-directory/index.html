What's in My Home Directory

⇐ previous
Posted 2026-10-24
  • aosa: source for the website of The Architecture of Open Source Applications.
  • archive: a GitHub repository with the remains of old projects.
  • asimpy: source for a discrete event simulation package I wrote.
  • bib: PDFs of 1800 papers, of which I’ve actually read about half.
  • bin: little software tools I’ve cobbled together.
  • books: PDFs of books I’ve bought.
  • bram: source for Jon Udell’s agent management tool.
  • catmaid: source for the Collaborative Annotation Toolkit for Massive Amounts of Image Data.
  • change: source for my workshop on organizational change.
  • chart.xkcd: source for an XKCD-style charting package I’m building.
  • closure: source for my workshop on project closure.
  • devsim: a placeholder for a student project simulating software development teams (to start in January 2027).
  • epub: epub versions of books I’ve bought.
  • fiction: stories I’ve written or am writing.
  • frml: source for a little program verifier I’ve built.
  • glosario: my clone of the Carpentries’ glossary project.
  • gvw: personal files (e.g., genealogical material my father and sister collected).
  • humans: source for a “Save the Humans!” game I started but never finished.
  • jazz: sheets for songs I’m learning to play.
  • mccole: source for a little static site generator I built.
  • mcq: source for a Quarto-based template for Carpentries-style lessons.
  • mrsp: source for my workshop on managing research software projects.
  • notwrong: source for my workshop on how to not be wrong when assessing the impact of AI.
  • nwit: source of the website for It Will Never Work in Theory.
  • overflow: source for a tool that checks remark.js and reveal.js slides for overflow.
  • rsdx: source for a book on research software design that I’ll probably never finish writing.
  • sdgc: source for the Sex and Drugs and Guns and Code series of blog posts.
  • sdm: a placeholder for a student project building a game (to start in January 2027).
  • sdxjs: source for Software Design by Example in JavaScript.
  • sdxpy: source for Software Design by Example in Python.
  • search: materials related to my ongoing job search.
  • selfdb: source for Mike Hoye’s tool that turns SQLite .db files into executables.
  • shunnify: source for a tool that turns Markdown files into Shunn-formatted manuscripts.
  • snailz: source for a synthetic data generator I built for a workshop I never taught.
  • sql: source for my short workshop on SQL for data scientists.
  • synths: source for a couple of synthetic data generators actually did wind up using.
  • third: source of this website.
  • travelers: source for a tower support game I started but never finished.
  • unbreak: source for my lessons on debugging and fixing software.
  • wallpaper: various screen wallpapers I’ve collected over the years.

And then of course there are various dot-files created by various tools, including but not limited to:

  • my aspell wordlist
  • my Bash profile and history
  • the .cache directory where tools like uv save things
  • the .bram, .claude, and .codewhale directories created by various AI tools
  • my Emacs configuration directory
  • my global Git configuration
  • NPM’s .npm directory
  • authentication tokens for various systems
  • the .ssh directory holding my SSH keys
